# Workspaces directory

This contains the manifests for containers made by/for RWS/Sonney

 - Mutt: kasm-terminal with mutt and sudo installed
 - Betterbird: kasm-firefox with betterbird as the default app
 - orgmode: Emacs for org-mode
 - adminterm: kasm-terminal with sudo, mutt, and emacs
 - sieve: Sieve Script Editor
 - kontact: Kontact KDE Office client
